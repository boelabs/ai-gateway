AI Gateway ofrece APIs compatibles con OpenAI y Anthropic. Tu aplicación envía solicitudes con una
**virtual key** y un nombre de **public model**. El gateway selecciona un deployment del proveedor,
traduce la solicitud y registra el consumo y su costo.

Tú configuras los proveedores, las reglas de routing y los límites de acceso. Las operaciones y
los parámetros disponibles dependen de los deployments de cada public model.

## Conecta una aplicación existente [#connect-an-existing-application]

Si un operador ya configuró AI Gateway, solo necesitas su URL base, una virtual key y el nombre de
un public model disponible. Por ejemplo, con el SDK de OpenAI para Python:

```python title="app.py"
from openai import OpenAI

client = OpenAI(base_url="http://localhost:4000/v1", api_key="<virtual-key>")
response = client.chat.completions.create(
    model="general",
    messages=[{"role": "user", "content": "Hello"}],
)
print(response.choices[0].message.content)
```

En este ejemplo, `general` es un nombre configurado en AI Gateway. Puede dirigir solicitudes a uno
o varios modelos upstream sin cambiar el código de la aplicación. Consulta la
[Referencia de la API](/docs/api-overview) para conocer la autenticación, los endpoints y los errores.
